# ADR 0005：已发布内容不可变，撤回与回滚切换公开指针

- 状态：已接受
- 日期：2026-08-07

## 背景

内容治理需要同时满足学术可追溯、多人并发安全和快速回滚。如果直接修改已发布行，历史引用、AI证据和页面快照将无法复现；如果回滚通过复制旧内容，又会制造没有必要的新版本。

## 决策

- `published`版本保持不可变，后续编辑必须从该版本创建新的`candidate`修订。
- 实体的`current_published_version_id`决定当前公开版本。
- 撤回将公开指针设为空，回滚将指针切换到已有的历史发布版本；两者都不修改历史版本内容。
- 发布、撤回和回滚在同一数据库事务中写入`publication_events`、`audit_events`和`outbox_events`。
- 撤回与回滚请求携带页面加载时的当前公开版本ID；指针已经变化时返回`412`，要求管理员刷新后重试。
- 发布前执行确定性的基础质量门禁，来源缺失和标准内容无正文属于阻断项。

## 结果

内容版本、公开状态和引用证据可以独立追溯。发布Worker只需根据Outbox重建搜索与静态投影，不需要猜测数据库中哪些更新属于一次完整发布。对象存储尚未接入前，数据库发布不会直接改写现有Git静态快照。
