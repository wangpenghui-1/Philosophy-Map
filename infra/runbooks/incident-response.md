# 事故响应手册

1. 记录开始时间、影响范围、`x-request-id`、当前 Git SHA、Vercel deployment ID 和健康状态，不复制用户 Prompt、Cookie 或 Token。
2. P1 立即冻结发布和后台写操作，轮换疑似泄露的密钥；静态公开快照保持在线。
3. 根据故障域隔离数据库、Redis、AI、媒体或邮件，不把外部服务异常扩散成公共阅读故障。
4. 数据完整性事件优先创建隔离副本调查，不直接修改生产历史版本或审计事件。
5. 恢复后验证权限矩阵、候选隔离、双用户 RLS、消息/记忆删除、媒体 quarantine 和快照版本。
6. 48 小时内完成无责复盘：时间线、根因、检测缺口、恢复耗时、用户影响和明确负责人。
