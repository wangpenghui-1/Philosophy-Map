# ADR 0001：模块化单体与静态快照回退

状态：已采纳

## 决策

根Next.js应用暂时保持原位，新增领域、数据库、知识、AI、鉴权和可观测性workspace包。后台API作为薄传输层调用这些包；异步任务由独立Worker入口消费事务Outbox。

公开页面继续使用构建期published快照。数据库读取将通过Repository逐路由启用，任何阶段都保留最近发布快照作为回退。

## 理由

当前团队与流量不需要微服务带来的独立扩缩容，却需要清晰领域边界、可测试契约和数据库故障隔离。暂不移动整个Next.js目录可以显著降低一次性回归范围。

## 后果

- 业务逻辑不得写在Route Handler或页面中。
- 包之间通过显式接口协作，不直接读取彼此内部文件。
- 只有观测数据证明需要时，才拆分搜索、AI或媒体服务。
